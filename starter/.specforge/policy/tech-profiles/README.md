# 技术栈 Profiles

本目录保存可复用的技术栈组合卡片。它不是强制清单，而是 design 阶段的决策素材：Agent 应从这里选择匹配项目的 profile，或说明为什么偏离。

## 使用方式

1. 进入 design 前，根据需求类型读取相关 profile。
2. 在 `design.md` 的“技术栈决策”中写明选中的 profile。
3. 如果引入未覆盖的框架、组件库、编辑器或测试工具，写明理由和后续是否需要补 profile。
4. profile 与项目已有约定冲突时，以项目约定为准，并记录偏离原因。

## 分类

- `frontend/`：前端框架、路由、样式和组件约定。
- `backend/`：后端运行时、API、数据访问和错误约定。
- `content/`：Markdown、富文本、编辑器和内容渲染方案。
- `testing/`：单元、集成、E2E 和浏览器验证组合。
