```text
请基于以下约束生成 UI 设计方案：

Product type:
Users / roles:
Primary task:
Design mode: Product UI / Brand Surface / Hybrid
Existing design system:
shadcn-vue usage: yes / no / unknown
Density: compact / comfortable / editorial
Foundations:
- colors:
- typography:
- spacing:
- radius / shadow:
- motion:
Pages:
Components:
Required states:
Accessibility:
Do not use:

输出：
1. Visual Style Brief
2. Page map
3. Component contract
4. State matrix
5. Motion notes
6. Anti-cheapness review checklist
```
