# PRD Quality Rubric

| 检查项 | 通过标准 |
|---|---|
| 问题清楚 | 能说明为什么做，不只是功能描述 |
| 用户清楚 | 至少有目标角色、场景、使用频率 |
| MVP 清楚 | 第一版做什么、不做什么明确 |
| 决策有依据 | 每个 MVP 项有用户价值、风险或证据 |
| 指标可观察 | 至少 1 个用户价值指标或业务指标 |
| 非目标清楚 | 明确防止 scope creep |
| 未决问题可见 | 高影响未知没有被隐藏 |
| AI / 数据风险可见 | 涉及时必须写清质量、成本、安全、人工兜底 |
| Handoff 可用 | requirements 能直接转译行为种子 |

## P0 问题

- 没有目标用户。
- 没有 MVP。
- 没有非目标。
- Agent recommendation 被写成用户确认。
- 成功指标完全缺失。
- 高影响未决问题被隐藏。
- PRD 写成技术方案。
