# Feedback To Feature Pool

```md
| Feedback / Request | Underlying opportunity | Candidate feature | Value | Complexity | Risk | Decision |
|---|---|---|---|---|---|---|
```

## Decision

- `mvp-candidate`
- `optional`
- `later`
- `reject`
- `needs-research`
- `needs-user-decision`

## Rules

- 客户说的功能不是自动进入 MVP。
- 同类请求要聚类成 opportunity。
- 高风险功能必须写 risk 和 validation。
- Agent recommendation 不能等于 user-confirmed。
