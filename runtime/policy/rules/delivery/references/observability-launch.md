# 上线观察和可观测性

## 日志

- 日志应作为事件流输出，交由运行环境收集和路由。
- 关键链路应有 trace id、request id 或 correlation id。

## 关键链路观察

新增后台任务、异步任务、同步链路、插件和网关能力，应能看到：

- 开始。
- 成功。
- 失败。
- 耗时。

## 指标和告警

指标优先围绕用户可感知行为：

- 可用性。
- 延迟。
- 错误率。
- 吞吐。
- 正确性。

告警应指向需要行动的问题，避免“有日志就告警”。

Google SRE 的 SLO 章节强调，指标应围绕用户真正关心的行为，而不是围绕“我们刚好能量到什么”。
