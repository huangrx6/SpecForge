# UI Design To Playwright

| UI design 输入 | Playwright 输出 |
| --- | --- |
| 页面地图 | route / navigation |
| 用户流程 | PW steps |
| 状态矩阵 | assertions / screenshots |
| 角色差异 | roles / auth setup |
| 表单 | fill / select / submit / validation |
| 上传下载 | upload / download assertions |
| 错误和权限 | negative flows |

若缺少稳定 locator，生成 finding：需要 implementation 添加 testid 或可访问名称。
