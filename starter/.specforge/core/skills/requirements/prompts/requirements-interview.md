# Requirements Interview Prompt

用于 requirements 阶段发现高影响未知。每轮只问一个会改变行为或验收的问题。

## 问题模板

```md
这个问题会影响 requirements 的 [行为 / 权限 / 数据 / 验收]，需要先定下来。

A) [选项 1] -> 影响
B) [选项 2] -> 影响
C) [授权默认] -> Agent 推荐与回退点

你选哪一种？
```

## 优先级

1. MVP 行为边界。
2. 角色 / 权限 / 数据安全。
3. 验收含义和失败路径。
4. 外部依赖 / 工具链决策。
5. UI / 技术设计输入。
