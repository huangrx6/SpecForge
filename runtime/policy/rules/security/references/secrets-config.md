# 密钥和安全配置

## 必做项

- 密钥不得硬编码在源码、模板、测试样例、日志或文档中。
- 生产密钥应通过环境变量、密钥管理系统或部署平台注入。
- 配置文件中的密码必须加密、引用密钥管理系统，或使用部署时注入的占位符。
- 示例配置必须使用假值。

## 生命周期

密钥应具备创建、轮换、吊销、过期和审计策略。

OWASP Secrets Management 强调密钥应具备可撤销性、轮换策略和访问审计。

## 泄露响应

1. 轮换密钥。
2. 评估 git 历史、日志、制品和外部副本。
3. 记录受影响范围。
4. 补充防再次泄露措施。

## Review Checklist

- 是否有 secret 进入仓库或日志。
- 是否定义密钥轮换与撤销。
- 是否有泄露后的处理流程。
