# Typography

## 层级

| 层级 | 用途 | 规则 |
|---|---|---|
| Display | 少量品牌页 / 大屏标题 | Product UI 默认不用 |
| H1 / H2 | 页面标题、分区标题 | 明确当前页面任务 |
| Body | 表单、描述、列表 | 不用过浅灰色承载关键信息 |
| Caption | 辅助信息、时间、来源 | 可读，不做装饰性小字 |
| Numeric | 指标、金额、百分比 | 等宽或对齐，单位清楚 |

## 规则

- 管理端标题克制，优先信息清晰。
- 表格和密集数据优先 13-14px，行高稳定。
- 按钮、标签、导航不要靠加粗堆层级；用位置、尺寸和状态区分。
- 中文界面避免负字距；英文缩写要配解释或 tooltip。

## 输出

记录字体家族、字号范围、行高、数字展示和长文本截断规则。
