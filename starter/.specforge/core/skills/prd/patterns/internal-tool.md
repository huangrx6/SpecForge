# Internal Tool PRD Pattern

适用后台工具、运营工具、配置台、管理端、客服工具和一次性效率工具。

## 必须确认

- 操作人角色、频率、权限和责任。
- 当前手工流程和失败代价。
- MVP 要减少哪一步人工操作。
- 审计、回滚、导出和权限边界。
- 是否需要培训、灰度和禁用策略。

## PRD 输出重点

- Current pain and failure cost。
- Scope & MVP Decision。
- Product Flow including exception path。
- Risks / Dependencies。
- Handoff To Requirements：权限、状态、数据文件和运行时种子。
