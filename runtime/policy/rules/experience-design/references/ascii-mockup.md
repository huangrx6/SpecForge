# ASCII Mockup Guide

ASCII / Markdown 线稿适合简单页面的快速布局说明。它可以作为 Pencil / Figma / HTML 的补充，但不适合复杂流程的唯一交付。

## 适用场景

- 1-2 个简单页面，主要是表单、列表、弹窗或配置项。
- 需求尚在早期，需要先快速对齐布局方向。
- 没有设计工具，且 UI 风险低。

不适用：

- 多角色、多页面、多步骤审批或复杂任务执行台。
- 需要响应式细节、图表、拖拽、编辑器、富文本。
- 需要正式视觉评审或高保真交付。

## 符号约定

```text
[ 输入内容 ]      输入框
[ 多行文本 ]      Textarea
[ v 选项 ]        Select
[x] / [ ]         Checkbox
(*) / ( )         Radio
( 按钮 )          次要按钮
([ 主按钮 ])      主要按钮
~~ 按钮 ~~        Disabled
[!] 错误提示      错误或警告
[i] 提示内容      信息提示
```

## 示例

```text
┌────────────────────────────────────────────┐
│  新建识别任务                         [x]  │
├────────────────────────────────────────────┤
│  任务名称                                  │
│  [ 客服对话意图识别 2026-05-14          ] │
│                                            │
│  TXT 文件                                  │
│  [ 选择文件 ]  conversations.txt           │
│  [i] 使用特殊分隔符切分每条对话            │
│                                            │
│  分隔符                                    │
│  [ ===NEXT===                            ] │
│                                            │
│  每分钟并发数量                            │
│  [ 60                                  ]   │
│                                            │
│              ( 取消 )  ([ 提交审批 ])      │
└────────────────────────────────────────────┘
```

## 在 ui-design.md 中使用

把 ASCII 线稿直接放在 `ui-design.md` 的原型证据章节，并标明它覆盖的页面和状态。复杂需求如后续改用 Pencil / Figma / HTML，应保留 ASCII 作为初始草案，不把它当最终证据。
