# Workflow / Approval PRD Pattern

适用：

- 审批。
- 状态流转。
- 发布 / 上线。
- 异步任务。
- 多角色操作。
- 撤回 / 重试 / 驳回。

## 必须确认

- 状态有哪些。
- 谁触发状态变化。
- 谁审批。
- 超时怎么办。
- 驳回怎么办。
- 撤回怎么办。
- 失败是否重试。
- 是否通知。
- 是否审计。

## PRD 输出重点

- Users / Roles。
- Product Flow。
- Exception path。
- Risk。
- Acceptance Seeds。
- Handoff To Requirements。
