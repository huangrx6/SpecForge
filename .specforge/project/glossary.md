# 术语表

| 术语 | 含义 |
|---|---|
| SpecForge | 仓库原生的 SDD 工作流框架 |
| SSoT | Single Source of Truth，长期项目事实源 |
| Change | 一个有边界、可审查、可验证、可关闭的工作单元 |
| Gate | 进入下一阶段前必须做出的决策点 |
| Artifact | 工作流产物，例如 requirements、design、tasks、review evidence |
| Artifact Graph | 描述产物、依赖、gate 和归档条件的工作流图 |
| Active Change | 正在推进中的 change |
| Archived Change | 已关闭、已归档的 change |
