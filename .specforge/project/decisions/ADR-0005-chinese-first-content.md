# ADR-0005: 中文优先内容

## 状态

Accepted

## 背景

SpecForge 当前主要使用中文语境设计，目标用户也以中文协作为主。如果核心规则和模板长期混用英文，会增加阅读和维护成本。

## 决策

SpecForge 的人类可读内容默认使用中文。保留英文的范围仅限：

- 命令、路径、文件名、包名、函数名、状态值。
- 外部项目或协议的原名。
- 与生态兼容必须保持英文的术语。

## 后果

- 后续新增或修改 `.specforge/`、`.specforge/`、`docs/` 时应优先使用中文。
- 已有英文文档需要逐步迁移。
- 研究文档可以引用英文项目，但结论和落地建议必须中文化。
