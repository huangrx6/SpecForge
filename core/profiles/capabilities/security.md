# Security Capability

用于鉴权、权限、敏感数据、签名、审计、注入防护和外部接口安全设计。

## 适用

- 涉及登录、单点、token、角色、数据权限、外部回调或开放接口。
- 存在手机号、身份证、账号、密钥、业务敏感字段或日志脱敏要求。
- 新增文件上传、下载、URL 跳转、富文本、AI 输入输出或第三方请求。

## 设计必填

- 认证主体、角色、权限矩阵和数据范围是什么？
- token / secret / sign 如何生成、传输、过期、轮换和存储？
- 输入校验、输出编码、SQL / XSS / SSRF / 跳转防护在哪里做？
- 敏感字段如何加密、脱敏、审计和控制日志输出？
- 失败响应是否稳定且不泄露内部细节？

## 验证

- 权限正负向用例、签名过期 / 重放 / 篡改用例。
- 敏感日志检查、上传下载边界、输入校验和错误响应。
- 高风险项需安全 review 或 code review 明确结论。
