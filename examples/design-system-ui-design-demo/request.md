# 新项目需求：城市生命线异常处置协同台

## 背景

建设一套给城市运维中心使用的 Web 页面套件，帮助值班长在管网、水务、电力、燃气等生命线系统出现异常时完成态势判断、事件研判、资源调度和复盘归档。

## 目标用户

- 值班长：需要快速判断风险等级、派发处置资源。
- 专家坐席：需要查看证据链、补充研判意见。
- 现场队伍：需要接收任务、反馈处置进展。

## 页面范围

1. 态势总览：查看全城风险热区、核心指标、正在处置事件和 AI 摘要。
2. 事件研判：聚合报警、视频、工单、专家意见，形成处置建议。
3. 资源调度：按距离、能力、负载和风险匹配队伍 / 物资。
4. 复盘中心：沉淀处置时间线、关键决策、证据和改进项。

## 设计要求

- 不是营销页，第一屏必须是可用的业务系统。
- 需要现代、高级、清透，但不能廉价科技大屏。
- 需要一套可落地到 Vue + shadcn-vue 的组件语言。
- 需要有动效边界：只服务状态变化和重点提醒。
