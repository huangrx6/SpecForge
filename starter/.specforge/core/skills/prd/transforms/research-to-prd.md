# 预研转产品需求文档

预研输入只转成产品决策证据、风险、约束、指标或开放问题；不直接写技术方案。

| 预研内容 | 产品需求文档位置 | 处理 |
|---|---|---|
| 已确认事实 | 背景 / 风险 / 快照 | 写事实、来源和影响 |
| 不清楚的事实 | 开放问题 | 写负责人和需要时间 |
| 服务商限制 | AI、数据与合规快照 | 写成本、延迟、限流或交付风险 |
| 竞品事实 | 候选功能池 / 风险 | 写参考，不当作必须照抄 |
| 合规 / 安全事实 | 风险 / 非目标 / 下游交接 | 写数据、安全、人工复核或需要预研 |

## 规则

- 当前事实不足以决定范围或指标时，决策状态 = `research-needed`。
- 技术事实只在产品需求文档中写产品影响，例如成本、延迟、可用性、合规限制。
- 产品需求文档不把预研验证的实现细节变成最小可行版本。
- 引用事实时记录来源文件和结论，不复制长篇预研内容。
