# Good Case

好的设计样例不是“漂亮截图”，而是能解释为什么适合宿主项目。

## Product UI 好案例特征

- 页面第一眼能看到主任务、状态和下一步。
- 组件重复规则稳定，用户能形成肌肉记忆。
- 表格、筛选、批量操作和详情入口清楚。
- 颜色服务语义，主色克制。
- 动效只强化反馈和状态变化。
- 有一个来自业务世界的 signature，例如诊断链路、资源拓扑、工单时间线，而不是装饰图形。
- 错误、空态、权限、加载和成功状态都像同一个系统。

## Brand Surface 好案例特征

- 首屏有明确对象和价值，不是抽象渐变。
- 视觉资产真实服务产品或品牌。
- 版式有节奏，但不牺牲阅读。
- 动效有叙事目的。
- 大胆只集中在一个维度，例如排版、媒体、动效或材质。

## DESIGN.md 好案例特征

- 不是截图描述，而是可复用规则。
- 有 atmosphere、palette、typography、components、layout、depth、motion、do/don't。
- 每个 token 有功能角色，不只是颜色名。
- 明确哪些规则应被 adopt / adapt / avoid。

## 给用户展示时

展示 2-3 个方向，每个方向写：

- 适合点。
- 风险。
- 采用什么。
- 不采用什么。
- 推荐理由。
- 这个方向的 signature。
