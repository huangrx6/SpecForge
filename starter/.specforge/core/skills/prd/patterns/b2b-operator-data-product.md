# B 端运营商与数据产品需求文档模式

适用：

- 运营商内部系统。
- 政企 / 大数据 / 客户经理工具。
- 数据看板 / 领导驾驶舱。
- 任务配置 / 报表 / 到期提醒 / 客户画像。
- 省市县多级权限。
- 含敏感客户数据。

## 必须确认

- 业务部门 / 使用部门。
- 业务 KPI。
- 目标用户角色。
- 使用频率和设备。
- 数据来源和更新频率。
- 数据口径和指标解释。
- 数据权限、地市权限、脱敏、审计。
- 导出、报表、订阅、告警。
- 灰度、回滚和运维责任。

## 产品需求文档输出重点

- 问题 / 目标结果。
- 用户 / 部门。
- 数据与合规快照。
- 范围与最小可行版本决策。
- 指标与评估。
- 交接给需求阶段。

## 常见风险

- 只写“支持查询”，不写查询对象、口径、权限和频率。
- 只写“数据看板”，不写指标解释和刷新机制。
- 只写“客户经理可见”，不写地市 / 角色 / 数据范围。
- 忘记导出、审计、脱敏和失败兜底。
