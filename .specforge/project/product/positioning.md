# Product Positioning

SpecForge is a repository-native SDD protocol for AI Agent collaboration.

## Audience

- Developers using coding agents on real repositories.
- Teams that want more structure than free-form prompting.
- Projects that need specs, reviews, validation, and project knowledge to stay aligned.

## Differentiation

| Compared With | SpecForge Position |
|---|---|
| Kiro-style IDE workflows | Keep the spec protocol repository-native and tool-portable |
| Spec Kit-style command flow | Add explicit static/dynamic directory separation and closure SSoT sync |
| cc-sdd-style harnesses | Keep boundary-first thinking, but make project SSoT a first-class area |
| Open agent harnesses | Learn from orchestration and context tools without coupling v0.1 to one agent runtime |

## Product Promise

SpecForge helps agents work from approved contracts, stay inside boundaries, leave verification evidence, and update long-lived project knowledge before closure.
