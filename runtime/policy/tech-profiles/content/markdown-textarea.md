# Markdown Textarea

## 适用

- MVP 内容编辑。
- 用户接受纯 Markdown 输入，不需要实时预览或富文本体验。

## 默认约定

- 使用 `<textarea>` 输入 Markdown。
- 保存原始 Markdown。
- 渲染 HTML 时必须考虑 XSS，按项目风险选择 sanitizer。
- 预览、图片上传、目录和代码高亮默认不包含，除非用户确认。

## 设计注意

- 明确是否需要实时预览。
- 明确支持的 Markdown 子集。
- 明确错误提示和未保存内容处理。
- 公网或多用户输入必须有 HTML 消毒策略。

## 验证

- 单元测试覆盖标题、列表、链接、代码块和危险 HTML。
- E2E 覆盖编辑后公开页面渲染。
