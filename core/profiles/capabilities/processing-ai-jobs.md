# Processing, AI & Jobs Capability

用于文件处理、批处理、LLM / AI 调用、限流、任务调度和结果输出相关能力选型。

## 适用

- 上传 txt / csv / xlsx / json 等文件并批量处理。
- 按分隔符、行、段落、记录切分输入。
- 调用 LLM、模型服务、Embedding、分类器或规则引擎。
- 需要并发控制、每分钟请求数、每日开始时间、审批后执行。
- 结果需要写入文件、对象存储、数据库或外部系统。

## Design 必填

- 输入格式、编码、分隔规则、最大文件大小和异常行处理。
- 任务状态机：draft / pending_approval / approved / running / paused / failed / completed 等。
- 并发与限流：全局、租户、任务级限制；失败重试和退避。
- AI 调用：模型、提示词版本、超时、重试、质量验收、人工复核。
- 输出：路径、格式、覆盖策略、权限、下载或回写方式。
- 审批：谁能提交、谁能审批、审批后是否允许修改。

## 验证

- 小文件、大文件、空文件、异常分隔符、中文编码。
- 并发限制是否生效。
- AI 失败、超时、返回非法 JSON 或低置信度。
- 审批前不可执行，审批后可执行。
- 输出路径不可写、重名、权限不足。
