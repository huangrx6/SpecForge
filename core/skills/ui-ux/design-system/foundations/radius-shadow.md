# Radius And Shadow

## 质感规则

- Product UI 默认圆角 6-8px；超大圆角只用于品牌页或特殊卡片。
- 阴影只表达层级和浮层，不做装饰。
- 表格、输入框、卡片优先用边框 + 背景层级，避免厚重投影。
- Modal / Popover / Dropdown 的阴影和边框要统一。

## 常见问题

- 所有容器都大圆角，会显得玩具化。
- 每张卡都有彩色阴影，会显得廉价。
- 边框、阴影、背景三者同时很重，会增加视觉噪音。

## 输出

记录：base radius、interactive radius、surface border、overlay shadow、禁止样式。
