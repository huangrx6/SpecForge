# Next.js API Routes

## 适用

- Next.js 全栈项目。
- 后端主要是同站 API、轻量 CRUD、表单提交或本地工具。

## 默认约定

- REST 资源命名优先。
- JSON 请求 / 响应。
- 错误响应使用 `{ "error": "message" }` 或项目约定的问题详情格式。
- 输入校验在 API 边界完成。
- 数据访问封装在 `lib/` 或项目既有目录。

## 设计注意

- 明确每个 endpoint 的 method、path、请求体、响应体和状态码。
- 公网部署或管理操作必须考虑认证、权限和 CSRF / 滥用风险。
- 同步数据库驱动只适合低并发或本地场景，生产负载需重新评估。

## 验证

- 集成测试覆盖成功、校验失败和不存在资源。
- 对 destructive 操作覆盖确认路径或 API 失败路径。
