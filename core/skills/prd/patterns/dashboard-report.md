# Dashboard / Report PRD Pattern

适用数据看板、报表、驾驶舱、指标分析、趋势监控和导出订阅。

## 必须确认

- 指标定义、口径、粒度和刷新频率。
- 用户角色、查看频率和决策动作。
- 数据源、权限范围、脱敏和审计。
- 空数据、延迟数据、异常值和口径变更提示。
- 导出、订阅、分享、截图或大屏展示是否进入 MVP。

## PRD 输出重点

- Desired outcome and decision users。
- Metrics & Evaluation。
- Data & Compliance Snapshot。
- Candidate Feature Pool。
- Handoff To Requirements：指标口径和可测试验收种子。
