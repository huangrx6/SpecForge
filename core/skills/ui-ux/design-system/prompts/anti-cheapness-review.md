# Anti Cheapness Review Prompt

```text
请审查这个 UI 是否有廉价感，并给出可执行修改。

检查：
1. 是否过度渐变、彩色阴影、大圆角、玻璃拟态。
2. 是否所有元素都抢主色。
3. 信息层级是否靠堆卡片和图标底色完成。
4. 文案、按钮、状态是否像模板。
5. 间距、对齐、表格、表单是否稳定。
6. 动效是否服务反馈，而不是装饰。
7. 是否符合宿主项目气质。
8. 是否有一个清晰 signature，还是只是装饰堆叠。
9. 是否能解释为什么属于这个产品，而不是任意同类产品。

输出：
- 主要问题：
- 修改建议：
- 保留项：
- 应删除的装饰：
- 应补齐的状态：
- 需要人工确认：
- 修改后应呈现的设计语言：
```
