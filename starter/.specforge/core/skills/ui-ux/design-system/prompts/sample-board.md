# Sample Board Prompt

用于在正式 Pencil 原型前，生成可供人工感官确认的样例板。

## Prompt

```md
基于以下需求和宿主产品，生成 2-3 个互斥 UI 方向样例。

输入：
- 产品类型：
- 目标用户：
- 使用场景：
- 实现栈：
- 已有设计系统：
- 不可接受风格：
- 关键页面：

每个方向输出：
- 方向名称：
- 适合点：
- 风险：
- 色彩 / 字体 / 密度 / 圆角 / 阴影 / 图标：
- 关键页面样例描述：
- 动效边界：
- 推荐指数：
- 需要用户确认的问题：

最后输出推荐方向和放弃其他方向的原因。
```

## Gate

方向会影响视觉气质、核心信息架构、组件形态或动效时，必须等待用户确认后再进入 Pencil。
