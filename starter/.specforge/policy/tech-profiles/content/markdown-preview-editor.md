# Markdown Preview Editor

## 适用

- 用户需要较好的写作体验。
- 文章、文档、知识库或博客后台。

## 默认约定

- 编辑区和预览区可以是 tabs 或双栏布局。
- 保存原始 Markdown，渲染结果可按性能需要缓存。
- 需要明确是否支持代码高亮、图片、目录、拖拽上传或快捷键。

## 设计注意

- 移动端通常使用编辑 / 预览 tab，不使用双栏。
- 未保存状态、离开确认和错误提示必须写入交互状态。
- 第三方编辑器库需要说明选择理由、体积和维护风险。

## 验证

- 单元测试覆盖 Markdown 渲染。
- E2E 覆盖编辑、预览、保存和重新打开。
