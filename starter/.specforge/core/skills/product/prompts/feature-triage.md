# Feature Triage Prompt

用于把用户反馈、功能请求和 solution candidates 归一成 feature pool。

```md
| Feedback / Request | Underlying opportunity | Candidate feature | Value | Complexity | Risk | Decision |
|---|---|---|---|---|---|---|
```

Rules:

- 客户提出的功能不是自动 MVP。
- 同类请求先聚类。
- 高风险项写 experiment 或 research handoff。
