# PC 端业务系统 UI 设计规范

适用范围：PC 端业务系统、运营后台、管理控制台、数据管理工具。默认设计基准为 `1920x920px`，并自适应低分辨率设备。

当 `ui-design.md` 选择本规范为设计系统来源时，AI 生成 Pencil 原型、HTML、CSS 或前端代码必须严格使用本文件定义的颜色、字号、行高、间距、尺寸和组件规则；不得临时改色、改字号、改圆角或引入未确认的视觉体系。

## 适用判断

| 条件 | 是否优先采用 |
|---|---|
| 内部管理系统、运营后台、审批台、配置台、数据表格系统 | yes |
| 以表格、筛选、表单、弹窗、抽屉、图表为主体 | yes |
| 用户明确提供或确认本规范 | yes |
| 营销页、品牌官网、移动 App、游戏、内容社区 | no |

如果项目已有更高优先级的企业设计系统，以项目设计系统为准；偏离本规范时必须在 `ui-design.md` 写明原因。

## 基础布局

| Token | 值 |
|---|---|
| 设计基准宽度 | `1920px` |
| 默认视口 | `1920x920px` |
| 顶部导航高度 | `64px` |
| 顶部导航扩展 | `64 + 8*n` |
| 侧边导航宽度 | `208px` |
| 侧边导航缩进态 | `68px` |
| 侧边导航扩展 | `200 + 8*n` |
| 模块间距 | `16px` |
| 页面结构 | 顶部导航栏 + 侧边导航 + 操作界面 + 背景层 |

## 字体

| 类型 | 字体 |
|---|---|
| 中文 | `"阿里巴巴普惠体 3.0", "Alibaba PuHuiTi 3.0", sans-serif` |
| 英文 / 数字 | `"D-DIN EXP", "DIN", monospace` |

行高公式：`字号 + 8px`。

| 字号 | 行高 | 用途 |
|---|---|---|
| `12px` | `20px` | 辅助文案 |
| `14px` | `22px` | 正文、导航、按钮、搜索框、选择器、分页器 |
| `16px` | `24px` | 小标题 |
| `18px` | `26px` | 中标题 |
| `20px` | `28px` | 大标题 |
| `22px` | `30px` | 扩展标题 |
| `24px` | `32px` | 页面主标题、强调数字 |

字重：

- 正文：`400`
- 标题：`500`
- 强调文本：`600`，仅限必要场景

## 颜色

### 品牌色

| Token | 值 | 用途 |
|---|---|---|
| Primary | `#277DEA` | 按钮、链接、选中态 |
| Primary Hover | `#4998FC` | 悬浮 |
| Primary Active | `#1D6BD0` | 点击 |
| Primary Disabled | `rgba(39, 125, 234, 0.5)` | 禁用 |
| Nav Expanded Bg | `rgba(2, 124, 251, 0.04)` | 导航展开背景 |
| Nav Hover | `rgba(2, 124, 251, 0.10)` | 导航悬停 |
| Nav Selected | `rgba(2, 124, 251, 0.10)` | 导航选中 |

### 功能色

| 语义 | 值 |
|---|---|
| Success | `#28CE89` |
| Warning | `#FFB92E` |
| Error / Danger | `#F56C6C` |
| Link | `#277DEA` |

### 中性色

| 用途 | 值 |
|---|---|
| 主要文字 | `#333333` |
| 次要文字 / 三级导航 | `#666666` |
| 辅助文字 | `#999999` |
| 遮罩层 | `rgba(0, 0, 0, 0.4)` |
| 浅色背景 / 选择器选中 | `#F5F7FA` |
| 描边色 / 滚动条 | `rgba(0, 0, 0, 0.10)` |
| 禁用背景 | `#F5F5F5` |
| 边框 / 分割线 | `#E8E8E8` |

使用规则：

- 主色只用于关键按钮、链接和当前选中态。
- 每页仅限 1 个主操作 `primary` 按钮，除非页面包含多个独立操作区。
- 功能色严格映射语义，错误色只用于危险、失败或破坏性操作。
- 文本颜色必须满足 WCAG 2.0 对比度要求。

## 侧边导航

|---|---|
| 常规宽度 | `208px` |
| 缩进宽度 | `68px` |
| 一级导航高度 | `44px` |
| 二级 / 三级导航高度 | `32px` |

## 图标

- 按钮图标：`16px`
- 标题、左侧导航、顶部导航图标：`18px`
- 使用统一 SVG 图标集，不使用 emoji。
- 图标需要与文本基线对齐，并为按钮补充 `aria-label`。

## 组件规格

### Button

| 项 | 值 |
|---|---|
| 高度 | `32px`，特殊场景允许 `32 +/- 4px` |
| 圆角 | `8px` |
| 左右内边距 | `16px` |
| 文字 | 居中 |

| 类型 | 规则 |
|---|---|
| Primary | 背景 `#277DEA`，文字白色，每页仅限 1 个主操作 |
| Default | 白底，边框 `#277DEA`，文字 `#277DEA` |
| Danger | 背景 `#F56C6C`，文字白色，必须二次确认 |
| Text | 无背景，仅文字，hover 变色 |

### Form

- 标签左对齐，固定宽度 `100px`。
- 输入区自适应填充剩余空间。
- 必填字段标签后显示红色 `*`。
- 校验错误实时内联展示，使用红色文本和错误图标。
- 禁用背景 `#F5F5F5`，禁用态无交互反馈。

### Input

| 项 | 值 |
|---|---|
| 高度 | `32px` |
| 圆角 | `8px` |
| 左内边距 | `12px` |
| 边框 | `rgba(0, 0, 0, 0.10)` |
| 聚焦边框 | `#277DEA` |

### Chart

- 图表采用 ECharts 或类似库。
- 主题色优先使用 `#277DEA`，辅助色使用功能色。
- 图表背景透明或白色。
- 坐标轴线色 `rgba(0, 0, 0, 0.10)`。
- 图例文字 `12px`，颜色 `#666666`。

## 交互与反馈

| 场景 | 规则 |
|---|---|
| 全局加载 | 页面级 Spin，遮挡内容区，颜色 `#277DEA` |
| 局部加载 | 表格、表单提交使用内联 Spin，颜色 `#277DEA` |
| 成功 / 失败 | Message 全局提示，右上角或顶部居中，3 秒消失 |
| 重要操作 | Confirm 弹窗 |
| 按钮 hover | 背景色加深或切换到定义 hover 色 |
| 输入 focus | 边框 `#277DEA`，有清晰焦点提示 |
| 键盘 | 所有组件支持 Tab 操作 |
| 图标按钮 | 必须添加 `aria-label` |

## 响应式

- 使用 24 列栅格系统。
- `lg >= 1200px`：多列布局。
- `md >= 992px`：适当缩减列数。
- `sm >= 576px`：单列或双列。
- 小屏间距缩小至 `8px` 或 `16px`。

## HTML / CSS 生成硬约束

生成 HTML/CSS 或前端组件时：

1. 所有颜色、字号、行高、间距、尺寸必须来自本文件。
2. 必须使用 `<style>` 或项目内样式文件定义 token；不得依赖外部未定义 CSS 库的默认值。
3. 可以使用 Tailwind、Ant Design 等库，但必须用本规范覆盖 token，而不是接受默认主题。
4. 禁止使用 emoji 充当图标。
5. 禁止为了“更好看”擅自引入渐变、毛玻璃、大圆角、超大 hero 或营销页式布局。
