# Settings Page

适用于系统配置、用户偏好、权限策略和集成配置。

## Layout

- 左侧分组导航，右侧配置表单；移动端分组折叠。
- 高风险配置独立区域，并提供说明、预览和确认。
- 保存策略明确：即时保存 / 手动保存 / 分区保存。

## States

default / dirty / saving / saved / validation-error / permission / conflict.

## Components

SettingsShell, SettingSection, SettingItem, DangerZone, SaveBar.
