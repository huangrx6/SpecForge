# Taste Review

用于审查 UI 是否有真实设计判断，而不是 AI 默认美化。

## Review matrix

| Dimension | Pass | Revise |
|---|---|---|
| Subject fit | 视觉来自产品世界和用户任务 | 任意同类产品都能套用 |
| One signature | 有一个明确记忆点 | 到处都想表现，焦点分散 |
| Restraint | 主色、阴影、动效克制 | 元素都在抢注意力 |
| Typography | 层级、数字、标签各司其职 | 默认字体和加粗堆层级 |
| Layout meaning | 结构编码业务关系 | 只是在排卡片 |
| Components | 有项目级 contract 和状态 | shadcn demo 直接堆页面 |
| Motion | 表达状态、进度、空间关系 | 装饰性飞入、弹跳、旋转 |
| Copy | 具体、可操作、用户语言 | 模板营销话术或系统术语 |

## Product UI taste

Product UI 的“高级”来自秩序，不来自装饰：

- 稳定网格、清晰任务入口、明确状态反馈。
- 信息密度和留白匹配使用频率。
- 组件状态完整，异常路径不糊弄。
- 色彩让状态更清楚，而不是让页面更热闹。
- 动效短、准、可关闭。

## Brand Surface taste

Brand Surface 的“高级”来自选择，不来自堆料：

- 首屏有一个明确 thesis。
- 视觉资产、排版或动效有一个主角。
- 文字和画面互相支撑，不重复表达。
- 大胆风格要有足够执行细节，否则宁可收敛。

## Mirror pass

交付前做一次镜子检查：

1. 去掉一个装饰元素，页面是否更好。
2. 把主色使用量减半，层级是否仍清楚。
3. 把标题换成真实业务文案，设计是否仍成立。
4. 截图缩到手机宽度，第一任务是否仍清楚。
5. 隐去所有图标，信息是否仍可理解。
